# Données françaises de Michna

Les traductions françaises intégrées à cette application proviennent du dossier `michnayot` du dépôt [micka-coder/talmedia](https://github.com/micka-coder/talmedia), révision `46e01ba8b7ecabf7e4195789580fad3beb548369`.

Chaque traduction conserve dans `lib/talmedia-fr.json` son crédit, la licence indiquée dans le fichier source et le chemin du fichier d’origine. L’application affiche le crédit et la licence sous chaque traduction française. Les licences des textes sont propres aux fichiers ; elles ne sont pas couvertes par la licence du code du dépôt Talmédia.

Seuls les chapitres dont le fichier source indique explicitement une licence ont été intégrés. Les 44 fichiers français sans mention de licence explicite à cette révision sont omis. Les textes sous CC BY-NC ou CC BY-NC-SA ne peuvent être réutilisés qu’en respectant les conditions de ces licences, notamment leurs restrictions d’usage commercial ; pour CC BY-NC-SA, les adaptations doivent aussi respecter le partage à l’identique. Consulter la notice de chaque fichier source avant toute redistribution ou utilisation commerciale.

Les traductions sont chargées depuis une copie locale du dépôt pour que la lecture ne dépende pas de la disponibilité de GitHub. Pour mettre les données à jour, reprendre les licences et crédits du dépôt source avant de remplacer cette copie.
